# Produktbrief

## Produkt

Spor økonomi er en enkel iOS-app for personlig økonomi.

Kjerneverdien er:

`Se hva du har igjen denne måneden.`

Appen skal hjelpe brukeren å få rask oversikt uten tungt budsjettoppsett, bankintegrasjon eller økonomisk sjargong.

## Målgruppe

Primær målgruppe:
- personer som vil ha enkel oversikt over månedens økonomi
- brukere som synes tradisjonelle budsjettapper blir for detaljerte
- brukere som vil registrere manuelt og beholde kontroll over egne data

Ikke primær målgruppe i MVP:
- brukere som forventer automatisk bankimport
- avanserte regnskaps- eller porteføljebrukere
- husholdninger med flerbrukerbudsjett og godkjenningsflyt

## Løfte

Spor økonomi skal gjøre det tydelig:
- hva som kommer inn
- hva som går ut
- hva som er igjen
- hvordan sparing og investering utvikler seg over tid

## MVP-Omfang

Inkludert:
- onboarding
- lokal bruk uten konto
- valgfri kontoflyt når backend er konfigurert
- budsjett med inntekt, utgifter, manuell sparing og gruppegrenser
- faste poster med månedlig auto-opprettelse
- oversikt med månedens netto og årsstatus
- mål og spareutfordringer
- investeringsoversikt med månedlige snapshots
- eksport og import
- juridiske sider og supportside

Ikke inkludert:
- bankintegrasjon
- automatisk transaksjonsklassifisering
- flerbruker eller delt budsjett
- avansert investeringsanalyse
- betalt abonnement som aktiv brukerflyt

## Produktprinsipper

- Enkelhet foran funksjonsbredde.
- Norsk språk i all UI.
- Offline-first som standard.
- Lav kognitiv belastning på hovedskjermene.
- Manuell registrering skal føles raskere enn å tolke kompliserte rapporter.

## Suksesskriterier

En første intern test er vellykket når:
- testbruker forstår Oversikt uten forklaring
- testbruker kan legge inn første transaksjon
- Budsjett og Investeringer føles som samme app
- eksport/import er forståelig og fungerer
- ingen debug-, premium- eller "kommer snart"-flater forstyrrer kjerneflyten
