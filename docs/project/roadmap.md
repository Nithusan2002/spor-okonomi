# Roadmap

## Nåværende Status

Appen har fungerende kjerneflyt for onboarding, budsjett, oversikt, investeringer, mål, faste poster, import/eksport og innstillinger.

Fokus nå er stabilisering, intern TestFlight og tydelig release-klargjøring.

## Fase 1: Intern TestFlight

Mål:
- verifisere førsteinntrykk og kjerneflyt på ekte enhet
- finne blokkere, krasj og uklarheter
- sjekke App Store-metadata og juridiske krav

Leveranser:
- grønn build
- intern smoke-test
- oppdatert TestFlight-tekst
- verifisert personvernskjema
- dokumenterte kjente begrensninger

## Fase 2: MVP-Release

Mål:
- sende en liten, ryddig og ærlig førsteversjon til App Store
- holde scope stabilt frem til innsending

Prioritert:
- onboarding og første registrering
- Oversikt
- Budsjett
- Investeringer
- Innstillinger, eksport/import og personvern

Ikke prioritert:
- bankintegrasjon
- AI-hjelper
- spareutfordringer
- tipsflate
- ny premiumlogikk
- avansert analyse
- større redesign

## Fase 3: Etter Første Release

Mulige forbedringer:
- bedre førstegangsoppsett for faste poster
- mer guidet mål-oppsett
- enklere månedsskifte
- tydeligere import/eksport-feedback
- mer presise tomtilstander
- lavfriksjons-påminnelser

## Beslutningsregel

Før MVP-release skal nye forslag vurderes slik:

1. Fikser dette en blocker eller tydelig uklarhet?
2. Reduserer dette risiko for avvisning eller dårlig førsteopplevelse?
3. Kan det leveres uten modellendring, migrasjon eller bred refaktorering?

Hvis svaret er nei på alle tre, flyttes forslaget til etter release.
