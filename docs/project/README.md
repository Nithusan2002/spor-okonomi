# Prosjektdokumenter

Denne mappen samler levende prosjektstyring for Spor økonomi.

## Filer

- `product-brief.md`: produktløfte, målgruppe, MVP-scope og suksesskriterier
- `roadmap.md`: releasefaser og prioriteringsregel
- `release-readiness.md`: sjekkliste før TestFlight og App Store
- `technical-plan.md`: arkitektur, dataflyt og teknisk risikobilde
- `data-model.md`: konseptuell datamodell og persistensprinsipper
- `design-and-user-flow.md`: hovedflyt, skjermroller og mikrocopy-retning
- `decisions.md`: stabile produkt- og teknologibeslutninger

## Ikke Opprettet Fra Referansebildet

Disse filtypene fra referansebildet er ikke laget fordi de ikke matcher nåværende MVP:

- admin-tool-dokumenter
- ingestion-workflow
- ingestion-connectors
- source-policy
- source-onboarding-template
- editorial-policy
- editorial-qa-checklist
- notification-strategy som egen fil

Varsler dekkes foreløpig i release- og teknisk plan. Hvis varsler blir en større produktflate senere, kan den få egen fil.
