## Vedlikehold

Oppdater berørt dokument når produktoppførsel, arkitektur eller arbeidsflyt endres.
Beskriv implementert funksjonalitet separat fra planlagt arbeid.
Release-sjekker skal bare markeres fullført når de er verifisert på aktuell build.

[Intern testing](../../INTERNAL_TESTING.md) beskriver smoke-test og feedbackrutine.
[Release-sjekklisten](release-readiness.md) samler godkjenningspunktene.
